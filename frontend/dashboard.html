教會數位選舉系統 - 操作手冊

本系統針對教會選舉提供嚴密的資安與設定環境：

  • 機構公印：請先在總覽設定好「機構公印」，系統才能自動在選票上加上防偽浮水印（系統會自動將印章轉換為紅色印泥效果，並襯於文字底層）。
  • 多重管理員：每個單位可設定多位管理員共同監票，實現更務實的防弊機制。
  • 完整稽核紀錄：為確保選務責任歸屬，系統內建嚴謹的操作稽核 (Audit Log) 機制。管理員的每一個新增、修改、刪除動作都會被永久記錄，任何異常操作皆有跡可循，確保選舉的絕對公正。

點選總覽畫面的「新增選舉」後進入管理頁面，可進行詳細的法規設定：

  • 當選門檻基準：可自由切換以「實際出席人數」或「總發票數(金鑰數)」作為過半門檻的計算基準，系統開票時將會自動運算公告，避免人為計算的爭議。
  • 強制分區限制：可設定各個分區的當選名額上限，確保區域代表性。
  • 保障名額：可指定某位候選人無條件保留一席當選名額。
  • 排除已當選：開啟後，若某位候選人已在其他項次(例如長老)當選，系統會在後續選舉(例如執事)中自動將其標示為停權，防止一人身兼多職。
  • 身分資格限制：可限制特定輪次僅限具備某些資格（如：牧師、長老）的人員參選。

  1. 名單建檔：請至「候選人資料庫」使用 Excel 批次匯入候選人名單與大頭照。
  2. 輪次微調：在總覽中點擊【調整名單】，透過雙欄穿梭框，可手動將符合資格的候選人加入本輪選票中。
  3. 產生金鑰：點擊【金鑰與選票發放】並輸入人數，系統會產生不重複的 8 碼一次性金鑰。
  4. 列印選票：點選一鍵列印，系統會產生 A4 排版的實體選票（含掃描用 QR Code 與機構紅色浮水印），供現場發放。

當選舉進入開票階段與跨輪次銜接時，系統提供強大輔助：

  • 手機即單槍 (主動推送)：管理員可直接在控制台將計票畫面同步推播至所有選民的手機中，克服場地硬體限制，萬人同看零延遲。
  • 智慧晉級嚮導：當一輪投票結束且需要進入下一輪（例如長老第一輪未選足額，需進行第二輪）時，系統會自動啟動晉級嚮導。它會自動扣除已當選人數來更新應選名額，並自動將已當選者從候選名單中剔除。無論是單選還是複雜的複選機制，嚮導都會為您算好一切，同時保留彈性修改介面，讓選務人員輕鬆銜接，不再手忙腳亂。
  • 發布與封存：當全數選完後，點擊「全局發布」公開當選名單，最後執行「封存」，選舉資料將轉為唯讀並永久歸檔於歷史報表中。

系統五大核心突破
  • 突破場地硬體限制：首創「手機即單槍」主動推送技術，控制台可將畫面即時推送到每位與會者的手機中，零死角同步掌握選舉動態。
  • 告別手忙腳亂的換場：「智慧晉級嚮導」在跨輪次時會自動運算並更新剩餘名額與候選名單，同時保留彈性修改空間，讓選務流程從容不迫。
  • 告別單機故障風險：全新跨平台網頁架構支援各大系統（包含 Mac 與平板），設備互為備援，大幅降低單點故障風險。
  • 萬人同時投票不卡頓：全面升級無伺服器 (Serverless) 企業級架構，突破連線限制，送出選票瞬間完成，不再需要漫長等待。
  • 監票機制更務實：銀行級資安與稽核紀錄，完整追蹤所有操作，並支援單一單位設定多位管理員，讓共同監票機制更加落實與透明。
版本更新梗概
  • v5.00 - 系統跨入 Serverless 企業級架構，支援萬人連線不卡頓；新增「手機即單槍」主動推送技術、以及「智慧晉級嚮導」，跨輪次自動運算名額與扣除當選名單。並優化操作稽核紀錄與仿紅印泥防偽浮水印。
  • v4.00 - 導入 LINE SSO 快速登入與多層級授權機制，提升管理員與會友連線資安控管。
  • v3.00 - 強化選舉法規引擎，新增「保障名額」、「強制分區限制」與「排除已當選」等複雜選務防呆機制。
  • v2.96 - 優化全局當選總覽數據聯集運算、自動強制跳轉機制。
  • v2.00 - 全面重構為無伺服器架構，引入多層級權限與 Firebase 雲端資料庫。
  • v1.00 - 系統正式上線，提供基本金鑰驗證與開票投影功能。
